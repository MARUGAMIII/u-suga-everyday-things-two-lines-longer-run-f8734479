A two-line explanation of a traffic jam for a 10-year-old, written for make.fun's "Everyday Things, Two Lines, Longer Run" bounty. Line 1 explains a traffic jam through one concrete, surprising analogy: a parking lot that escaped onto the road and forgot to let anyone leave. Line 2 is honest about that analogy: it says what the parking lot covers (cars packed tight, nobody able to pass) and what it leaves out (every car is still awake, with a driver inside waiting for a gap to crawl forward).

The entry program writes those two lines to `/output/entry.txt` — plain ASCII, two lines, one sentence each, within 1-400 characters — and reads the file back to verify it passes the gate before finishing.

## Run it

```sh
python3 main.py
```
